TITLE
    Portfolio Andrew Torres

DESCRIPTION
    My portfolio made using React. About me page, projects, resume, and contact form made available to viewer to better get to know me and contact me with any questions. 

DEPENDENCIES
    react
    react-router-dom
    react-icons
    emailjs
    dotenv
    
EXECUTION
    Clone repository from Github.
    Download Node if not installed already.
    Open folder in Visual Studio Code.
    Navigate to portfolio-andrew-torres.
    use 'npm install' command to download dependencies.
    Use 'npm start' command.
    Browser should open and display project.
